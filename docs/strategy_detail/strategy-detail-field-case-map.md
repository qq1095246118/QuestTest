# 策略详情字段与测试用例映射

本表按字段查看策略详情的验证范围。`主线 Case` 是前面 60 条主用例，`资源 Case` 是新增的信号、批次、持仓、订单等原子数据用例。所有字段都要同时核对原始值、归属区间、snapshot/generation 和缺失状态。

## 页面核心指标（当前数据 / 历史累计数据）

## 当前明显缺口

- `signals`、`signal-batches`、`rebalance-plans`、`order_intents`、`orders`、`fills` 目前只有资源路径/少量 Oracle，尚未完成真实响应字段断言。
- `Sharpe`、`Sortino`、`胜率`、`盈亏比` 和策略仓位分母需要最终业务口径。
- 8 个核心指标从分钟事实到真实策略接口的统一 snapshot/generation 链路仍需 fixture。
