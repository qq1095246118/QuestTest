# 策略详情完整数据用例清单

本清单重新盘点后共 **139 条主 Case**：旧主用例 60 条（字段/身份 20 条，公式/风险/执行 40 条），新增数据资源原子用例 79 条。页面联动、导出和账户级分润动作不纳入本清单。

## 统一执行要求

- 当前数据取同名策略的运行中账号，历史数据取全部历史归属区间；同名跨交易所合法聚合。
- 先按策略切换记录划分 `interval_id`，再过滤分钟权益、收益、手续费、资费、持仓和执行事实，最后跨账户汇总。
- 每条 Case 的公共追踪字段为 `strategy_id/account_id/exchange/interval_id/source_id/snapshot_id/generation`。
- 缺失、0、估算、partial、unavailable、conflict 分开验证。

## 与当前自动化的关系

- 当前策略详情执行入口已经改为 `--live --env test` 的真实链路；未连接测试环境时只会门禁跳过，不把离线计算结果计为通过。
- 本清单中新增的资源原子用例明确列出了之前没有真正断言的数据域：summary/series 响应字段、positions 生命周期、signals、signal-batches、rebalance-plans、order_intents、orders、fills 以及跨域链路。
- 标为“待补充自动化”的 Case 不能因为接口白名单或静态 JSON 注册而视为通过；需要补充独立 fixture、响应字段断言和清理验证。
- `CALC-033`～`CALC-042` 的账户分润/清算动作不纳入本清单，继续由账户详情/分润用例覆盖。
