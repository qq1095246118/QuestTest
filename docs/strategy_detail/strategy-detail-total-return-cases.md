# 策略详情总收益率 Case 清单

## 统一口径

策略详情总收益率按策略维度计算：

```text
策略总收益率 = Σ策略归属区间收益 / Σ策略归属区间有效本金
```

不能平均账户收益率，不能把同一账户本金重复计算，也不能把其他策略区间带入当前策略。

## Case 清单

|编号|场景|数据设计|预期|
|---|---|---|---|
|RETURN-001|当前数据单账户基线|当前运行中的 Alpha 账户，有效本金10000、策略收益100|当前总收益率=1%|
|RETURN-002|历史累计单账户|账户历史运行 Alpha，已停止，累计有效本金10000、策略收益100|历史 Tab 仍显示1%，当前 Tab按当前成员规则处理|
|RETURN-003|当前多账户汇总|Alpha 当前运行在两个账户，本金10000/20000，收益100/400|总收益率=500/30000，不是10%和20%的平均值15%|
|RETURN-004|同名策略跨交易所|Binance和OKX均运行同名 Alpha，各有独立本金和收益|两个交易所均纳入 Alpha；相似名称策略不纳入|
|RETURN-005|账户多策略隔离|同一账户先运行 Alpha，后运行 Beta|Alpha 总收益率只取 Alpha 区间，Beta 收益不能进入 Alpha|
|RETURN-006|Alpha→Beta 切换|Alpha 区间本金10000、收益300；Beta 区间本金12000、收益500|Alpha收益率=3%，不把Beta的500计入|
|RETURN-007|Alpha→Beta→Alpha|Alpha 两段收益100/−50，本金10000/12000；中间 Beta 有独立收益|Alpha使用两段 Alpha 的收益和本金；Beta不计入|
|RETURN-008|多账户不同切换时间|A1、A2分别在不同时间切换到/切出 Alpha|按每个账户自己的 Alpha 归属区间计算，不能按当前策略反推历史|
|RETURN-009|切换导致有效本金变化|Alpha 第一段本金10000；切换后重新进入 Alpha，本金12000|前后区间使用各自本金，不把10000或12000错误复用到全部区间|
|RETURN-010|确认入金和出金|初始本金10000，确认入金2000，确认出金500，策略收益300|有效本金按10000+2000−500=11500；资金流不计入策略收益|
|RETURN-011|正负收益抵消|账户A收益500、本金10000；账户B收益−200、本金20000|总收益率=300/30000=1%，先汇总金额再除本金|
|RETURN-012|零收益|有效本金大于0，策略收益为0|总收益率为真实0，不返回 null或缺失|
|RETURN-013|零/负有效本金|策略收益非0，但有效本金为0或负数|总收益率不可用；不能返回0、Infinity或NaN|
|RETURN-014|收益缺失|一个 Alpha 区间有收益，另一个区间收益缺失|返回 partial/unavailable，并指出缺失区间；不能把缺失收益当0|
|RETURN-015|本金缺失|一个 Alpha 区间有收益但本金缺失|不能用其他区间本金补齐；不能跨区间拼接分子和分母|
|RETURN-016|收益和本金分别缺失|区间A缺收益、区间B缺本金，区间C完整|只能使用完整区间形成诊断值，并标记 partial；不能把A的本金与B的收益配对|
|RETURN-017|手续费和资费不重复计入|同一策略区间有已实现收益、手续费、资金费|先绑定策略收益字段口径：若使用区间净交易收益则按ΔG−ΔC+ΔF；若使用策略归因G则费用/资费不重复进入；两种口径都不能重复计算|
|RETURN-018|空策略/无有效区间|策略不存在有效 Alpha 归属区间|返回空或不可用，不显示普通0|
|RETURN-019|当前与历史结果对照|当前只包含运行中区间，历史包含停止区间|两个 Tab 分别使用各自成员集合，不能复用同一个总收益率|
|RETURN-020|账号收益与策略收益隔离|一个账户同时运行Alpha、Beta，账户全历史收益为1000|Alpha详情只使用Alpha归属收益，不能直接显示账户全历史1000|

## 计算示例

```text
Alpha 区间1：收益400，本金10000
Alpha 区间2：收益−120，本金12000
Alpha 区间3：收益600，本金20000

策略总收益率 = (400−120+600) / (10000+12000+20000)
             = 880 / 42000
             = 2.095238%
```

## 不纳入本字段清单的内容

- snapshot/generation 冲突
- 迟到和重放
- 网络重试
- 页面刷新和控件联动

这些属于通用数据链路或页面用例，不作为总收益率字段的业务 Case。
