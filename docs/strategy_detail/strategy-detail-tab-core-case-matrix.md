# 策略详情核心指标完整用例矩阵

本矩阵以页面的当前数据/历史累计数据两个 Tab 为范围，覆盖截图中的 16 个核心指标，共 **51 条字段级 Case**：3 条范围 Case + 每个字段当前/历史/边界各 3 条。

## 统一范围规则

- 当前数据：只取当前运行中的同名策略账号和当前有效策略区间。
- 历史累计数据：取同名策略的全部历史归属区间，包括停止、结束和解绑历史。
- Alpha→Beta→Alpha 必须保留两个 Alpha 区间；空窗不计入运行天数、收益率分母和风险样本。
- 每个字段同时记录 `strategy_id/account_id/exchange/interval_id/source_id/snapshot_id/generation`。
