# 策略看板五阶段结果级用例索引

这份索引把原来的粗粒度分类拆成可执行场景。每条详细用例都必须有明确样本、操作步骤、独立手算或字段对照、接口断言和页面断言；没有可控源数据时只能记录为“样本缺口”，不能直接判为产品缺陷。

本轮只覆盖五段链路：

1. 策略侧最终结果接入；
2. 基础接口返回和页面展示；
3. 基础字段派生指标计算；
4. 收益、资金、回撤和强平风险告警；
5. 分润触发、锁单、收款确认、清算和清算后更新。

权限、报告导出、策略内部信号算法、计算端原始中间过程、性能、安全、物理表结构和额外数据血缘不在本轮。字段检查只按字段说明、字段含义、单位、正负号、状态语义、接口返回和页面展示直接对照。

2026-09-22已重新读取在线UI稿及批注，页面字段、精度、固定列、Tab、分页、刷新和策略切换标记的最新核对依据见 [UI稿同步基线](strategy-dashboard-ui-baseline-20260922.md)。该同步不增加主用例数量，不代表完整业务回归已执行；原型底图、批注和当前部署的差异在基线中分别记录。

页面精度采用用户最新确认的规则：USDT撤回固定2位例外，与其他普通数值统一6位；百分比2位；非百分比且 `0 < abs(x) < 0.000001` 的极小数10位，均指小数点后位数并向零截断。百分比优先于极小数规则；`0.00000089 USDT → 0.{6}89 USDT`，同值BTC数量也显示 `0.{6}89 BTC`，末尾补零不作新增强制要求。本轮USDT显示6位不报Bug。只改变展示，不提前截断接入、计算、入账或排序原值；具体边界输入及预期保存在既有24个展示子场景的数据文件中，本地规则更新不代表真实页面渲染已全部验收。

## 自动化执行入口

pytest 入口位于 [test_result_cases.py](../tests/cases/strategy_dashboard/test_result_cases.py)，会注册全部 175 条稳定编号。执行命令：

```bash
pytest -q tests/cases/strategy_dashboard
```

执行入口有两个明确模式。默认的 `contract` 模式逐条检查 175 条用例是否具备稳定编号、前置/数据、具体步骤和期望/断言；它只证明用例描述结构完整，不能证明真实接口适配器可执行，也不产生业务接口通过结论。命令如下：

```bash
pytest -q tests/cases/strategy_dashboard
```

真实业务使用 `QUEST_STRATEGY_DASHBOARD_MODE=live`，并通过 `QUEST_STRATEGY_DASHBOARD_EXECUTOR=module:function` 注入适配器。适配器接收一条用例元数据，负责调用策略结果查询、看板接口和页面替代入口，并在业务断言失败时抛出断言异常：

```bash
QUEST_STRATEGY_DASHBOARD_MODE=live \
QUEST_STRATEGY_DASHBOARD_EXECUTOR=your_adapter_module:execute \
pytest -q tests/cases/strategy_dashboard -m strategy_dashboard
```

live 模式缺少适配器时会明确失败并显示 `BLOCKED_AUTOMATION`，不会跳过，也不会把未执行的业务用例误报为通过。当前仓库已完成契约入口和用例元数据迁移；真实结果级适配器仍需绑定实际查询端点、响应 Schema、样本选择和页面结果替代方案。

## 每条用例的执行顺序

1. 记录账号、策略、稳定业务 ID、查询时间、统计范围、状态、接口请求条件和原始接口响应；不使用页面截断或格式化后的值反推计算。
2. 先做源结果或字段对照，再做接口断言，最后做页面断言；页面和接口值不一致时记录为展示映射问题，接口和独立核算均错误时记录为结果/计算问题。
3. 对每个边界样本单独执行，不用“同一条用例覆盖低于、等于、高于”来掩盖实际缺少的样本。每个场景至少有一个正向样本和一个对照样本。
4. 如果前置字段为空、样本不足、分母为零或上游返回部分失败，检查系统是否明确返回不可用状态；系统把缺失数据静默变成 0 或完整汇总时，才判为结果处理问题。
5. 对文档尚未签认的规则，只记录当前实际返回和规则差异，不把两个相反候选结果同时判为通过。

## 必须使用的统一计算口径

下面这些口径已经写入 CALC 和 SET 用例，不能在不同文件中重新解释：

- `D` 是合格入金减出金；入出金不能直接计入已实现交易收益。
- `G` 是累计毛已实现收益；区间净交易收益按 `ΔG - ΔC + ΔF`，其中手续费支出 `C` 为正、资金费 `F` 带符号。
- 钱包、权益以最新业务文档的 M01 和确认后的字段定义为准；如果服务仍返回互相冲突的两套口径，记录为公式口径冲突，不任选一个通过。
- 累计账户收益率是 `G / D`；清算后展示收益率是 `(G - Gclear) / (D + Gclear)`；计费周期收益率是 `(G - Gbase) / (D + Gclear)`。`Gbase` 和 `Gclear` 不能互换。
- 年化收益率少于 7 天不可计算；运行日、时区、日界线尚未签认的差异记录为规则待定。
- 策略贡献使用策略净收益除以所有策略净收益绝对值之和；有正有负时有符号合计不必等于 100%。
- 分润按账户出账。达到周期门槛后，对整个合格计费收益乘冻结分润比例，不能只对超过门槛的差额收费。
- 锁单后立即开启后继计费周期；锁定应收不随当前行情回算。收款登记、财务确认和清算是三个状态，待审核款不计确认实收。
- 清算失败不清零、不撤销已确认收款；网络超时先记为未知/处理中，查询到明确结果后再更新；清算成功后展示周期可重置，但真实净值和历史事实必须保留。
