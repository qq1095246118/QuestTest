## 下一轮采用的页面检查基线

精度以用户最新确认“USDT也改为六位，这个可以先忽略”为准：撤回USDT固定两位的例外，USDT与其他普通数值统一向零截断到小数点后6位；百分比按源字段单位转换后向零截断到2位；非百分比且 `0 < abs(x) < 0.000001` 的极小数（包含USDT）向零截断到10位，再把连续前导零写成 `{n}`。恰好 `±0.000001` 使用普通规则，百分比不进入极小数规则。该变更仅影响展示，计算、入账和排序使用各自契约下的原值；末尾补零及千位分隔样式未另行规定。本轮USDT显示6位不报Bug，本地规则更新不代表全部边界已在页面验收。

原型底图曾展示多位价格、计划权重-0.01374246和两位名义价值/手续费，作为历史来源保留；当前按用户最新确认的6/2/10位规则验收。USDT `1.23456789 → 1.234567`、`-1.23456789 → -1.234567`、`0.00000089 → 0.{6}89`，整数12无需强制补足末尾小数零；普通权重 `-0.01374246 → -0.013742`；ratio `0.123456789 → 12.34%`；BTC数量 `0.00000089 → 0.{6}89`，其中6表示小数点后首个非零数前有6个零。USDT或BTC数量 `0.00000099999 → 0.{6}9999`，不能进位成0.000001；截断后显示0的数，接口原值不得改写为0或缺失。
