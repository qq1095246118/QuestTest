## 历史 follow-up 清单迁移

### CALC-051 最近到账取实际到账时间

- 优先级：P1
- 前置/数据：同一账单有多笔已确认收款，登记、审核和实际到账时间不同且跨月。
- 步骤：读取账单、收款明细和总览最近到账字段，分别隐藏登记或审核时间。
- 期望：最近到账取已确认收款最大实际到账时间；待审核凭证不参与；无已确认款返回不可用。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺账单集合详情适配器。

### CALC-052 逾期严格边界

- 优先级：P0
- 前置/数据：当前时刻等于到期、晚一秒、未到期、足额到账、待审核和无到期时间的账单。
- 步骤：逐组读取账单状态、应收、实收、待收和到期时间。
- 期望：严格晚于到期且待收大于零才逾期；等于到期、足额、无到期时间或待审核不得误标逾期。
- 自动化状态：`RULE_PENDING`，逾期起算点和待审核规则需签认。

### CALC-053 累计净值与清算周期净值分离

- 优先级：P0
- 前置/数据：有累计收益、清算后收益、清算点及两条完整时间序列。
- 步骤：读取累计曲线、周期曲线和净值卡，独立按 M03/M04 对账。
- 期望：累计和周期曲线分别使用各自基准；清算只重置周期曲线，累计历史不丢失。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺独立 M29/清算曲线来源。

### CALC-054 固定本金净值的资金流边界

- 优先级：P1
- 前置/数据：无资金流和日内入金/出金两组完整权益序列。
- 步骤：分别读取固定本金净值，记录现金流时点和窗口。
- 期望：无资金流按批准固定本金计算；有资金流按已签认调整规则计算或明确不可用，不能把本金变化当收益。
- 自动化状态：`RULE_PENDING`，资金流调整算法未签认。

### CALC-055 闭合交易胜率边界

- 优先级：P1
- 前置/数据：全赢、全亏、平手、未平仓、部分平仓和缺费用归属交易。
- 步骤：读取交易统计，记录样本单位和窗口外事件。
- 期望：按批准的闭合交易/事件单位统计；未平仓不计入错误的亏损或平手；无样本不可用。
- 自动化状态：`RULE_PENDING`，交易样本单位未签认。

### CALC-056 平均盈亏比与利润因子分离

- 优先级：P1
- 前置/数据：盈利/亏损笔数不等、全赢、全亏、极小值和接近抵消样本。
- 步骤：读取平均盈亏比、profit factor、盈利亏损笔数及金额。
- 期望：两个指标使用各自定义和分母；无亏损或无盈利返回明确不可用，不输出 Infinity 或互相替代。
- 自动化状态：`RULE_PENDING`，指标命名和分母需签认。

### CALC-057 Sortino 与 Sharpe 分母独立

- 优先级：P1
- 前置/数据：全正、全负、正负混合、零波动和无下行样本。
- 步骤：读取两项风险指标及样本数、频率、无风险收益字段。
- 期望：Sharpe 使用批准总波动分母，Sortino 使用批准下行偏差；零分母不可用，不相互复制。
- 自动化状态：`RULE_PENDING`，下行分母和目标收益率未签认。

### CALC-058 仓位率、净敞口与保证金分母隔离

- 优先级：P0
- 前置/数据：多空抵消、净敞口为零但毛敞口非零、零/负/缺权益、逐仓和全仓保证金。
- 步骤：读取持仓敞口、保证金、权益和三个比率，记录分母字段。
- 期望：分子、分母和抵消规则分别对账；缺分母只使对应指标不可用，不能用另一个比率代替。
- 自动化状态：`RULE_PENDING`，跨合约抵消和分母规则未签认。

### CALC-059 多币种费用与内部转账

- 优先级：P1
- 前置/数据：USDT 交易、BNB 手续费、缺汇率费用、内部转账出入两端和外部出入金。
- 步骤：读取费用、资金流和净入金，分别提供事件价/期末价/缺汇率样本。
- 期望：按批准汇率时点折算；缺汇率不可静默为零；内部转账组合净额为零且不计交易收益，外部出入金仍影响净入金。
- 自动化状态：`RULE_PENDING`，汇率时点和资金分类未签认。

### VIEW-141 页面默认窗口与时区边界

- 优先级：P1
- 前置/数据：29 日、30 个完整风险日、168 小时执行窗口和 UTC/UTC+8 日界线事件。
- 步骤：不设置筛选打开总览、执行、风险和详情，再用相同日期范围重查。
- 期望：各组件使用各自批准默认窗口；控件、请求参数、曲线和统计首尾一致；未闭合日按规则排除或标记。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺页面执行器；日切规则另待确认。

### CALC-060 精确证据计费资格

- 优先级：P0
- 前置/数据：USD、完整 G/D、有效来源水位、未来时间、过期快照和精确合格快照。
- 步骤：逐组触发分润评估并读取资格状态、拒绝原因和账单。
- 期望：只有币种、G/D、来源水位和时效全部合格才可锁单；不合格不生成有效账单且保留具体原因。
- 自动化状态：`RULE_PENDING`，快照年龄、未来容差和水位契约未签认。

### CALC-061 首个合格快照建立 Gbase

- 优先级：P0
- 前置/数据：启用前有历史 G，启用后首个精确快照和无合格快照两组样本。
- 步骤：读取启用前、首个快照及后继周期，核对 Gbase 建立时间和计费资格。
- 期望：Gbase 只能由首个合格快照建立；无合格快照不可计费；启用前收益不被静默追溯。
- 自动化状态：`RULE_PENDING`，首周期追溯规则未签认。

### CALC-062 C1 修订向 C2 传播不双重扣减

- 优先级：P0
- 前置/数据：C1 已锁单，累计收益随后下修，C2 已按锁单边界开启。
- 步骤：读取修订前后 C1/C2、Gbase、Gclear 和账单，核对历史冻结与当前累计。
- 期望：旧应收不被静默改价；C2 以批准边界计算；同一修订不能同时从 C1、C2 双重扣减。
- 自动化状态：`RULE_PENDING`，修订传播和更正动作未签认。

### DATA-121 运行、全登记、外部启用与归档全集

- 优先级：P0
- 前置/数据：running、stopped、外部 enabled、unknown、archived 和绑定已结束对象。
- 步骤：分别读取当前运行、全登记、外部启用和历史全集，比较对象集合和计数。
- 期望：每个范围按定义返回完整集合；unknown/归档/外部启用不静默映射为 stopped，也不从历史全集删除。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺全状态目录和历史关系适配器。

### DATA-122 E/W/U/G/C/F 共同水位与重置

- 优先级：P0
- 前置/数据：六类账户字段来自不同采集时点，另有计数器重置和部分字段延迟更新。
- 步骤：读取字段、更新时间、来源水位和派生指标，比较水位及余额关系。
- 期望：不同水位不能拼成正常完整结果；重置或不一致时返回 partial/unavailable 和原因，不用旧 E 配新 U/G/C/F。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺字段共同水位来源。

### ALERT-012 陈旧、未来或非 USD 来源不触发精确告警

- 优先级：P0
- 前置/数据：数值达到收益/回撤/资金门槛，但来源过期、未来、缺失或非 USD；另有精确合格样本。
- 步骤：逐组读取告警评估、来源时间、币种和拒绝原因。
- 期望：只有精确合格来源才按阈值触发；陈旧/未来/缺失/非 USD 返回 unknown/待补数据，不显示正常达标。
- 自动化状态：`RULE_PENDING`，精确告警证据契约未签认。

## 数据源与跨层一致性

### DATA-123 多接口同一快照一致

- 优先级：P0
- 前置/数据：同一账号和策略同时存在总览卡片、历史曲线、执行、持仓四类结果；查询期间推进一次源批次。
- 步骤：记录四类接口的 `snapshot_id`、`generation`、`as_of`、账号/策略 ID 和窗口；再打开对应页面。
- 期望：四类结果必须绑定同一代次；若不能同代返回，必须整体标记 `partial`/`refreshing`，不能新卡片拼旧曲线或旧执行。页面标题、更新时间和数值与接口同代。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺策略/账号详情及浏览器适配器。

### DATA-124 源批次原子提交与半批次重试

- 优先级：P0
- 前置/数据：A、B 两个账号属于同一采集批次；首批 A 成功、B 失败，随后只重试 B。
- 步骤：读取首批结果；提交 B 的重试；重新读取目录、汇总和批次状态。
- 期望：首批不能标记为完整，A 的值不能复制给 B；重试只补 B，不重复 A；完成后计数、部分状态和批次 ID 一致，半写批次不能用于正常总览。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺采集批次提交/重试入口。

### DATA-125 跨来源身份与版本对齐

- 优先级：P0
- 前置/数据：目录已到 `g2`，财务、执行或持仓仍为 `g1`；策略-账号关系另有版本号。
- 步骤：同时查询目录、关系、资金、执行和持仓接口，记录来源代次和关系版本。
- 期望：跨代次结果不能拼成 `complete`；应返回 `partial`、`STALE_SOURCE` 或等待重采状态，并保留冲突来源，不能静默使用旧代次。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺跨来源代次入口。

### DATA-127 策略、账号与组合层级守恒

- 优先级：P0
- 前置/数据：一个账号绑定两策略、同一策略绑定多账号，另有未归因收益和共享费用。
- 步骤：分别读取策略列表、账号列表、关系、策略贡献和组合汇总；按物理账号去重后独立汇总。
- 期望：共享账号资金只计一次；策略贡献按批准归属口径与组合结果对账；未归因/多归因必须显式 partial 或保留，不得静默丢失或复制。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺策略详情及归因来源。

## 接口参数与故障边界

### API-142 全页面筛选与窗口参数组合契约

- 优先级：P1
- 前置/数据：准备 `from>to`、`from==to`、未来窗口、最大范围、只给一端、空/重复/未知账号 ID，以及状态、交易所、策略多条件组合。
- 步骤：对总览、策略、账号、执行和风险接口逐组发送参数，记录 HTTP、错误码、空结果和请求回显。
- 期望：非法窗口和未知身份按接口契约返回 4xx 或明确空/不可用；AND/OR 组合固定且清除一个条件不污染其他条件；禁止回退到默认全量。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，具体 400/空结果及筛选逻辑需以接口契约落定。

### API-143 瞬态失败恢复与重试幂等

- 优先级：P0
- 前置/数据：同一请求依次模拟 503、超时、429 后恢复 200；另模拟旧请求晚于新请求返回。
- 步骤：发起带 request/correlation ID 的查询并重试；比较每次响应的代次、更新时间和事实数量。
- 期望：错误不能转为空集合；重试不重复追加事实；恢复后的成功响应同时切换代次和值。若页面保留旧值，必须带失效标识；晚到旧响应不能覆盖新条件。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺故障注入和页面网络拦截器。

## 页面交互与显示

### VIEW-142 多筛选、深链与返回上下文

- 优先级：P1
- 前置/数据：总览、策略和账号页面同时设置交易所、账号、商务、策略、研究员、状态、日期筛选。
- 步骤：筛选后翻页，进入详情，再执行浏览器后退/前进和直接深链打开。
- 期望：控件、URL/路由、请求参数、选中Tab、页码和排序按产品规则一致；稳定ID解析策略详情的同名跨交易所总览，不把列表的交易所/运行状态筛选强制继承为详情限制；返回列表恢复原筛选。相似名称不混入，账号详情仍按稳定账号身份隔离。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺页面执行器和稳定路由映射。

### VIEW-143 异步请求乱序不覆盖新条件

- 优先级：P0
- 前置/数据：快速从筛选 A 切换到 B，令 A 响应晚于 B；再在当前/历史 Tab 间快速切换。
- 步骤：记录请求序列、响应代次和最终 DOM/图表数据。
- 期望：最终页面只显示 B 的 ID、标题、代次、指标和曲线；A 的晚到响应被丢弃，Tab 切换不混入另一 Tab 数据。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺浏览器网络拦截器。

### VIEW-144 分类数据失败隔离

- 优先级：P1
- 前置/数据：金额接口成功、曲线接口超时、执行接口 partial、持仓接口返回完整空集合。
- 步骤：同时打开页面并分别恢复失败接口；观察各区块状态和后续刷新。
- 期望：金额显示值、曲线显示不可用、执行显示 partial、持仓显示空态；账户整体不能被渲染成无数据，恢复时只刷新受影响区块，不能用 0 替代失败。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺页面响应替换执行器。

### VIEW-145 列表到详情的身份与原值一致

- 优先级：P1
- 前置/数据：存在同名或同前缀的策略/账号；详情含持仓、执行、分润和图表弹窗。
- 步骤：从列表进入对象，依次展开详情、图表和弹窗，再返回列表并切换另一对象。
- 期望：每个请求使用稳定ID；策略详情按同名策略跨交易所集合对账，不以单行金额、账号数或状态为预期；从同名不同交易所行进入，在相同Tab/窗口/来源下结果一致。从不同名称策略或不同稳定账号进入，不能残留前一对象数据；接口原值而非展示截断值参与对照。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺详情 API/页面执行器。

## 计算与降级矩阵

## 详情响应复合对象

### API-146 详情响应复合对象同范围守恒

- 优先级：P0
- 前置/数据：同一次策略或账号详情请求同时返回 `context`、`counts`、`freshness`、`execution`、`exposure_summary`、`status_summary` 和 `profit_sharing`。
- 步骤：记录请求的 subject、strategy/account ID、scope、population、window、selection 和 `as_of`；再将计数、更新时间、执行时间、敞口及账单统计与明细集合逐项对照。
- 期望：所有对象回显同一 subject、scope、window 和代次；counts 与返回集合守恒；freshness 时间不能晚于当前请求时间；执行时间字段格式和来源一致；状态计数不重复；来源缺失只影响对应区块，不能用另一对象的结果补齐。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，缺策略/账号详情 API 及完整响应字段映射；风险分母、TTL 和利润分成周期口径另按规则确认。

### CALC-066 详情复合字段的同代次与依赖隔离

- 优先级：P0
- 前置/数据：同一冻结结果包含账户/策略状态、持仓敞口、执行摘要、分润账单和收益指标；分别制造持仓、执行、账单来源缺失。
- 步骤：每次只删除一个来源区块，读取完整详情响应并记录 `snapshot_id`、`generation`、`as_of`、状态和 counts。
- 期望：已知区块仍返回原值；缺失区块和仅依赖它的派生字段变为 unavailable/partial 并带原因；不把 metrics、旧缓存或其他账户结果复制到缺失区块；完整输入时各区块同代次且总数/金额/状态守恒。
- 自动化状态：`DESIGNED_NOT_CONNECTED`，等待详情响应适配器；不把当前 overview 的 8 项指标对账当作本用例通过。

### CALC-063 账号、策略与组合层级守恒计算

- 优先级：P0

## 流程与生命周期

### FLOW-141 停止、重启与重新绑定归属

- 步骤：依次读取停止前、停止后、重启后、重绑定后的策略、账号、历史和账单接口。

### FLOW-142 动作完成后的全页面读穿

### FLOW-143 两会话并发动作冲突与幂等
