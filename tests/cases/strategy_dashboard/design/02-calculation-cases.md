# 计算结果细化用例

## 使用边界

本文件只核对已经返回到看板的基础结果和其派生结果，不测试策略内部信号算法。每条用例都按下面的顺序执行：

1. 选取或准备一组有明确截止时间、账号、策略和统计窗口的源结果；
2. 读取接口返回的基础字段和派生字段；
3. 使用未四舍五入的基础值独立手算；
4. 对照接口值、页面值和页面显示格式；
5. 如果前置字段缺失或最终口径未确认，记录为“样本缺口/规则待定”，不把猜测结果判成产品 Bug。

每条用例的结果记录固定拆成三栏：

- **接口断言**：接口原值、null/不可计算状态、字段单位和统计窗口与独立手算结果一致；
- **页面断言**：总览、策略详情、账号详情或对应 Tab 的值与接口原值对应，展示统一向零截断，不做四舍五入；USDT与其他普通数值统一截断到小数点后6位；百分比按源字段单位转换为百分数后截断到2位；非百分比且 `0 < abs(x) < 0.000001` 时截断到10位后把连续前导零写为 `{n}`。价格与数量同样按实际单位及数值类别核对，末尾补零不额外强制；页面格式化只影响展示；
- **边界断言**：低于/等于/高于阈值、分母为零、样本不足、缺历史依赖或时间边界时，返回明确的业务状态，不用 0、Infinity、NaN 或上一时点结果静默替代。

通用样例可以使用：`D=11000`、`G=1100`、`U=250`、`C=80`（正支出费用）、`F=-30`（支付资金费）、`W=11990`、`E=12240`。该样例只用于说明结果级核对，不能替代接口实际返回值。

后文中的手算小数用于说明计算关系，不是页面固定显示精度。计算层按精确表达式及既有业务规则核对，页面层统一执行上述向零截断：例如当前回撤 `1/12` 显示 `8.33%`，贡献 `2/3` 显示 `66.66%`、`-1/3` 显示 `-33.33%`；不得先把中间结果四舍五入后再用于页面或后续计算。

## 1. 账户基础计算

### CALC-001 钱包、浮盈和权益三项关系

- 优先级：P0
- 依据：PDF M01、贯穿数字样例
- 前置：读取同时返回 `E=12240`、`U=250`、`G=1100`、`C=80`、`F=-30` 的账号。
- 步骤：
  1. 读取钱包余额、未实现盈亏、保证金/权益字段；
  2. 手算 `W=E-U=11990`；
  3. 分别核对页面卡片、账号详情和接口值。
- 期望：钱包、浮盈和权益符合 M01 及最终确认的保证金口径。若页面仍使用 `W=D+G`，而权益又单独加减费用和资金费，必须标记为公式口径冲突，不能任选一个结果通过。

### CALC-002 净入金正值

- 优先级：P0
- 依据：PDF M03/M19。
- 前置：累计合格转入 12000，累计合格转出 1000。
- 步骤：查询账号资金字段并计算 `D=12000-1000`。
- 期望：净入金为 11000；入出金不增加已实现收益 G；页面和接口金额相同。

### CALC-003 只有资金流变化

- 优先级：P1
- 前置：在两个时点之间只发生转入/转出，G、U、C、F 不变。
- 步骤：查询区间收益和累计收益率。
- 期望：资金流只改变 D 和相应余额；区间净交易收益不因入出金产生；累计 G 不增加。

### CALC-004 已实现与未实现分离

- 优先级：P0
- 前置：先固定 G，改变 U；再固定 U，改变 G。
- 步骤：分别查询两组结果。
- 期望：U 的变化只影响权益/保证金及风险曲线；G 的变化影响累计收益和分润计算；两者不能互换。

### CALC-005 手续费和资金费的符号

- 优先级：P0
- 前置：准备手续费支出 C=80、资金费支付 F=-30，以及资金费收入 F=+30 的两组结果。
- 步骤：分别计算区间净交易收益和页面总费用。
- 期望：手续费按文档正支出字段处理；资金费按带符号值处理；支付资金费不能显示为收益，收入资金费不能被反向扣除。

### CALC-006 累计收益率正值

- 优先级：P0
- 前置：G=1100、D=11000。
- 步骤：手算 `G/D` 并查看总览、策略详情和账号详情。
- 期望：累计收益率为 10%；三个页面口径一致，页面截断不改变接口原值。

### CALC-007 累计收益率负值和零值

- 优先级：P1
- 前置：分别准备 G=-1100、G=0、D=11000。
- 步骤：分别查询两组账号快照的 G、D、累计收益率和页面状态，并独立计算 `G/D`。
- 期望：分别显示 -10% 和 0%；亏损颜色、符号和汇总方向正确。

### CALC-008 非正净入金

- 优先级：P0
- 前置：D=0、D<0 两组数据，并保证 G 非零。
- 步骤：分别查询 D=0 和 D<0 的接口及页面结果，检查收益率字段、可计算状态和页面卡片。
- 期望：收益率为 null/不可计算；不返回 Infinity、NaN 或伪造 0%；页面不能把该账号当作 0% 正常账号。

### CALC-009 区间净交易收益

- 优先级：P0
- 前置：区间内 `ΔG=600`、`ΔC=30`、`ΔF=-20`。
- 步骤：计算 `600-30-20=550`。
- 期望：区间净交易收益为 550；不把 ΔU、入金或出金重复计入；金额与区间边界一致。

### CALC-010 区间边界不重计

- 优先级：P0
- 前置：在起点、终点和终点后一秒各准备一个事件。
- 步骤：分别按 `[start,end)` 查询相邻两个区间。
- 期望：终点事件只进入后一个区间；相邻区间合计等于全区间；任何事件不重复计数。

## 2. 时间序列和风险指标

### CALC-011 年化收益少于七天

- 优先级：P0
- 依据：PDF M05。
- 前置：运行时长 1、6、6.99 个自然/有效运行日，具体窗口以已签认口径为准。
- 步骤：分别按三个运行时长查询年化收益字段，记录接口状态和页面展示，并与七天门槛逐一比较。
- 期望：少于 7 天时年化收益不可计算；不能通过向上取整为 7 天绕过门槛。

### CALC-012 年化收益达到七天

- 优先级：P0
- 前置：同一收益率分别运行 7、30、365 天。
- 步骤：按 `累计收益率/同口径运行天数×365` 计算。
- 期望：年化使用同一收益率口径和同一运行日定义；7 天的结果不套用 30 天窗口。

### CALC-013 运行日定义待确认

- 优先级：P1
- 依据：T02。
- 前置：自然日 10 天但有效运行日 7 天、167 小时两组样本。
- 步骤：分别查询两组样本的运行天数、年化收益及时间字段，记录接口采用的日界线和时区，并保留两种算法的差异。
- 期望：记录系统采用的日界线、时区和运行日定义；在负责人确认前，不将两种算法的差异判为实现 Bug。

### CALC-014 日收益率

- 优先级：P0
- 前置：连续完整日权益 `E0=100`、`E1=110`、`E2=99`。
- 步骤：计算 `r1=10%`、`r2=-10%`。
- 期望：日收益使用权益相邻时点比值；资金流导致的权益跳变按最终批准的资金流规则处理，不能直接当成交易收益。

### CALC-015 样本标准差和年化波动

- 优先级：P0
- 前置：至少 2 个完整日收益，另准备 1 个未闭合当日。
- 步骤：按样本标准差分母 `n-1` 计算，再乘 `sqrt(365)`。
- 期望：未闭合日按规则排除；n<2 时波动率为 null；接口和页面不使用总体标准差替代样本标准差。

### CALC-016 Sharpe

- 优先级：P1
- 前置：准备正波动、负收益和零波动三组日收益。
- 步骤：分别读取三组日收益、年化收益和年化波动，独立计算 Sharpe，并核对接口、页面及不可计算状态。
- 期望：按 `年化收益/年化波动` 计算；零波动返回 null；不返回无穷大。

### CALC-017 Calmar

- 优先级：P1
- 前置：准备有回撤和最大回撤为 0 的两组数据。
- 步骤：分别查询两组年化收益、最大回撤和 Calmar，独立计算 `年化收益/abs(最大回撤)`，再核对页面状态。
- 期望：按 `年化收益/abs(最大回撤)`；最大回撤为 0 时不可计算。

### CALC-018 当前回撤

- 优先级：P0
- 前置：权益路径 `100→120→110`。
- 步骤：在最后时点计算 `(120-110)/120`。
- 期望：当前回撤为 8.333333%；峰值必须来自当前点之前，不能用全序列最低值直接相减。

### CALC-019 最大回撤

- 优先级：P0
- 前置：权益路径 `100→120→90→110`。
- 步骤：按时间顺序读取完整权益路径，在每个时点计算历史峰值、当前回撤和最大回撤，并对照接口和页面结果。
- 期望：当前回撤 8.333333%，最大回撤 25%；峰值必须先于谷值。

### CALC-020 缺历史峰值

- 优先级：P0
- 前置：只返回当前权益和一个低点，没有完整历史峰值。
- 步骤：查询缺失历史峰值的结果，检查回撤字段的值、状态和缺失依赖说明，并核对页面是否保留不可计算状态。
- 期望：最大回撤/当前回撤标记缺少历史依赖或不可计算，不能用当前值伪造完整回撤。

### CALC-021 图表抽稀不改变指标

- 优先级：P1
- 前置：同一权益路径分别以完整点和抽稀点展示。
- 步骤：用相同账号、窗口和截止时间分别请求完整序列与抽稀序列，读取两组指标并对比图表点数与统计结果。
- 期望：图上点数可以不同，但最大回撤、波动率和 Sharpe 使用完整计算路径，结果不因绘图粒度变化。

## 3. 归因、执行和持仓指标

### CALC-022 策略贡献正负分母

- 优先级：P0
- 前置：策略 A 净收益 100，策略 B 净收益 -50。
- 步骤：按绝对值分母 150 计算。
- 期望：A=66.666667%，B=-33.333333%；有符号贡献合计 33.333333%，不能强制显示为 100%。

### CALC-023 贡献分母为零

- 优先级：P0
- 前置：所有策略净收益均为 0。
- 步骤：查询全为零收益的策略贡献列表和总览，检查贡献分母、占比字段及页面的不可计算状态。
- 期望：贡献占比不可计算；不能平均分配，也不能用 0% 掩盖分母为零。

### CALC-024 Top6 贡献展示

- 优先级：P1
- 前置：策略数超过 6 个。
- 步骤：查询超过 6 个策略的完整贡献集合和总览 Top6，核对 Top6 排序、其他项金额/占比及集合总额。
- 期望：总览只显示 Top6 时，Top6 合计不被误标为 100%；若接口提供“其他”，其金额和占比必须能对账。

### CALC-025 计划匹配率按目标数

- 优先级：P0
- 前置：100 个有效目标中 99 个成功，分布在 2 个批次，其中一个批次只成功 1 项。
- 步骤：读取完整目标明细、批次和成功状态，分别按目标数和批次数计算匹配率，并核对接口与页面值。
- 期望：匹配率为 99%，不能按批次平均成 50%。

### CALC-026 替换、取消和零目标

- 优先级：P1
- 前置：准备被替换计划、取消计划、零目标平仓计划。
- 步骤：按业务目标读取原计划、替换计划、取消事件和零目标平仓事件，按最终生效状态去重后计算匹配结果。
- 期望：按最终生效计划及已批准的零目标规则计数；同一业务目标不能因替换事件重复计算。

### CALC-027 健康度缺项

- 优先级：P0
- 前置：缺失回撤、净敞口、保证金使用率或匹配率中的任一必需分项。
- 步骤：分别构造缺失每个必需分项的结果，查询健康度接口和页面卡片，记录缺失字段及最终状态。
- 期望：健康度为 null/不可计算；不能用 0 分或上一时点分数补齐。

### CALC-028 健康度评分边界

- 优先级：P1
- 依据：M13、T05、算法说明页。
- 前置：分别准备各分项在评分端点及端点两侧的值。
- 步骤：逐一查询端点以下、端点、端点以上的健康度分项和总分，记录实际映射、截断及页面显示，和已批准规则逐项比对。
- 期望：只有正式批准的评分端点和线性插值规则才能作为通过标准；未确认端点只记录实际结果和规则差异，不把候选规则当成已批准断言。

### CALC-029 持仓数量和名义价值

- 优先级：P0
- 前置：同一账号含重复拉取记录、零仓位、双向仓位和多个合约。
- 步骤：读取完整持仓明细，按合约和方向去重并过滤零仓位，独立计算唯一持仓数和绝对名义价值后核对汇总。
- 期望：持仓数为完整集合中的非零唯一仓位数；总名义价值按绝对名义汇总；重复记录不重复计数。

### CALC-030 订单完成率

- 优先级：P1
- 前置：同一订单包含多个状态事件，部分订单完全成交、部分订单部分成交。
- 步骤：读取订单及其状态事件，按订单 ID 取最新状态，分别统计完全成交订单和唯一订单总数后核对完成率。
- 期望：按唯一订单的最新状态统计；完全成交订单/唯一订单；事件记录不能重复计数。

### CALC-031 成交均价

- 优先级：P1
- 前置：同一订单有数量 2@100、数量 1@110 的有效成交。
- 步骤：计算 `(2×100+1×110)/3=103.333333`。
- 期望：使用数量加权均价；不同单位或不相容合约不合并计算。

### CALC-032 执行延迟

- 优先级：P1
- 前置：同一执行链触发 0 秒、计划 2 秒、最后完成 9 秒；另有其他链的最近触发时间。
- 步骤：读取同一执行链的触发、计划和完成事件，计算 9 秒延迟，并与其他链的时间字段隔离核对。
- 期望：延迟使用同一链的触发和完成事件；最近触发与最近完成可以不是同一批；不能跨链相减。

## 4. 清算展示和分润计算

### CALC-033 清算后展示收益率

- 优先级：P0
- 前置：`G=1300`、`Gclear=1300`、`D=11000`。
- 步骤：按 `(G-Gclear)/(D+Gclear)` 计算。
- 期望：清算时展示收益率为 0；钱包/真实累计收益不被物理清零。

### CALC-034 清算后新增收益

- 优先级：P0
- 前置：清算后 G 从 1300 增至 1400，D=11000，Gclear=1300。
- 步骤：分别读取清算前后 G、Gclear、D、展示收益率和累计收益率，独立计算清算后新增收益并核对两个页面字段。
- 期望：展示收益率为 `100/12300=0.813008%`；累计收益率仍按累计 G/D；两个字段不能互换。

### CALC-035 计费周期收益

- 优先级：P0
- 前置：`Gbase=500`、`G=1100`、`D=11000`、`Gclear=0`。
- 步骤：计算计费收益 600、本金 11000、周期收益率 5.454545%。
- 期望：使用 Gbase，不把历史累计 G 当成周期起点。

### CALC-036 分润本金含清算基准

- 优先级：P0
- 前置：`D=11000`、`Gclear=1300`、`Gbase=1100`、`G=1300`。
- 步骤：读取分润计算所用 D、Gclear、Gbase、G 和本金字段，独立计算 `D+Gclear`，并检查后继周期基准是否被改写。
- 期望：分润本金为 12300；清算基准只影响本金，不移动后继周期 Gbase。

### CALC-037 毛收益计费范围

- 优先级：P0
- 前置：周期内同时存在已实现收益、手续费、资金费和未实现收益。
- 步骤：读取周期起点和当前 G、手续费、资金费、未实现盈亏及计费收益，独立计算 `G-Gbase` 并对照账单。
- 期望：计费收益按 `G-Gbase`；手续费、资金费和未实现盈亏不能被重复加到分润收益中。

### CALC-038 应收金额半入舍出

- 优先级：P1
- 前置：构造计费收益×分润比例产生超过 8 位小数的金额。
- 步骤：读取未舍入计费收益、冻结比例和应收金额，使用 HALF_UP 保留 8 位核对接口及账单入账结果；再以该结果独立应用页面向零截断规则核对展示。
- 期望：账单计算/入账仍按 HALF_UP 保留 8 位，本次 UI 规则不改变该业务精度；USDT账单页面与其他普通数值统一向零截断到6位，满足极小数条件时截断到10位后压缩前导零。两层分别验收，不能要求页面显示全部8位，也不能用截断后的显示值反向改写账单。

### CALC-039 达标边界

- 优先级：P0
- 前置：分别准备周期收益率低于、正好等于、高于 5%，且 G-Gbase>0、D+Gclear>0。
- 步骤：分别查询三组周期收益率、达标状态和账单金额，独立比较 5% 边界并核对整段计费收益。
- 期望：正好达到阈值即可达标；低于不达标；高于达标；不能只收超过 5% 的部分。

### CALC-040 达标前置条件

- 优先级：P0
- 前置：分别关闭账号、计费收益为 0、本金为 0、精确证据缺失。
- 步骤：逐一查询四组前置不满足的账号结果，检查达标状态、锁单状态、拒绝原因和页面提示。
- 期望：任一必要条件不满足都不能锁定账单；不能只依据页面收益率显示达标。

### CALC-041 首次接入无历史清算

- 优先级：P0
- 前置：账号历史存在 G=500，但没有真实清算证据；后续 G=700，D=10000。
- 步骤：查询首次接入的历史收益、清算证据、Gbase、Gclear 和展示/计费结果，记录系统选取的初始基准。
- 期望：不能把历史 G=500 当 Gclear；按最终实现规则处理首次展示和首次 Gbase，并将追溯口径差异标记为待确认。

### CALC-042 锁单后继周期

- 优先级：P0
- 前置：C1 在 G=1100 锁单，之后 G=1300。
- 步骤：读取 C1 锁单前后的 G、账单状态、C1 应收和 C2 基准，核对锁单边界与后继周期时间线。
- 期望：C1 应收不随行情变为新金额；锁单边界立即结束 C1 并开启 C2，C2 的 Gbase 为锁单边界 G。

### CALC-043 账户收益和策略收益不可互换

- 优先级：P0
- 前置：账号总收益 600，策略 A=400、B=150、人工/未归因 50。
- 步骤：分别读取账户账单收益、策略贡献明细和未归因项，独立汇总策略贡献并与账户总收益及账单字段对账。
- 期望：账单按账户收益规则计算；策略贡献只能用于归因展示；不能把账户总收益复制给 A/B，也不能用比例硬补未归因。

## 5. 结果格式和不可计算状态

### CALC-044 原值与页面舍入

- 优先级：P1
- 规则：沿用已有中文标题；标题中的“页面舍入”在本用例中统一指向零截断，不代表四舍五入。仅更新 UI 展示规则，CALC-038 的账单入账规则保持不变。
- 前置：准备具有多位小数的 USDT 金额、其他单位金额、比例、价格和数量，覆盖正负数、零、极小数阈值两侧及截断后归零的数；价格、数量标明实际单位，比例样本标明接口使用小数比率还是百分数单位。链路样本遵守源字段有效精度；超过源字段精度的10/11位输入仅用于页面单层展示验证，不作为账单入账原值或后端缺陷依据。
- 步骤：读取接口原始值、页面显示值和后续账单输入；先按实际单位分类，并按源字段单位转换百分比，再用十进制原值独立计算向零截断结果；逐项核对卡片、表格和图表提示中相同字段的显示，以及后续计算是否仍使用原值。
- 期望：USDT撤回固定2位例外，与其他普通数值统一向零截断到6位；百分比转换完成后截断到2位，始终不进入极小数规则；非百分比且 `0 < abs(x) < 0.000001` 时截断到10位后将连续前导零写为 `{n}`，阈值等于 `±0.000001` 时走普通规则。价格、数量须核对实际单位及数值类别，不能将百分比或极小数一概显示6位。正负数均向零截断，不能对负数使用向负无穷取整；展示结果不能反向影响收益、费用、应收和阈值判定，本轮USDT显示6位不报Bug。
- 样本与期望：USDT及其他普通数值 `1.23456789 → 1.234567`、`-1.23456789 → -1.234567`，整数12无需强制补零。小数比率 `0.0123999 → 1.23%`、`-0.0123999 → -1.23%`，源字段已为百分数 `1.23999` 时也为 `1.23%`，不得重复乘100。非百分比极小数（含USDT） `0.00000089 → 0.{6}89`、`-0.00000089 → -0.{6}89`、`0.00000099999 → 0.{6}9999`、`0.00000000019 → 0.{9}1`，对应负数仅改变符号；`±0.000001` 不使用压缩格式，`±0.00000000009` 截断后数值为0。小数比率 `0.00000089` 转换为百分数后仍按2位显示 `0.00%`，不得显示为极小数压缩格式；所有类别末尾补零样式不额外强制。

### CALC-045 负分母、零波动和缺样本

- 优先级：P0
- 前置：分别构造本金非正、波动为 0、回撤为 0、只有 1 个完整收益样本、必需基准缺失。
- 步骤：逐一查询五组边界结果，检查相关指标的原始值、不可计算状态、缺失原因和页面显示。
- 期望：相关比率统一返回 null/不可计算；不返回 Infinity、NaN、无意义的 0 或上一时点结果。

### CALC-046 同一窗口一致性

- 优先级：P0
- 前置：同一账号、策略、起止时间和截止时间同时查询总览、策略详情和账号详情。
- 步骤：使用相同查询参数读取三个页面/接口的基础字段和派生指标，按指标口径逐项对账并记录允许的 Tab 差异。
- 期望：相同口径的指标一致；当前、累计、清算后和计费周期指标允许不同，但页面必须能由字段/Tab 解释差异。

### CALC-047 图表缺口处理

- 优先级：P1
- 前置：时间序列中存在断点、单点和未闭合桶。
- 步骤：读取包含断点、单点和未闭合桶的时间序列，检查图表标记及各统计指标实际使用的样本集合。
- 期望：缺口断开或明确标记；不补 0 进入回撤、波动率和收益计算；单点可以展示但不能证明完整统计。

### CALC-048 数据不足但基础值可用

- 优先级：P1
- 前置：权益、已实现收益可用，但风险指标缺少历史路径。
- 步骤：查询同一结果的基础字段和风险指标，分别记录可用值、缺失依赖、接口状态及页面卡片。
- 期望：保留可计算的基础字段和小计；仅依赖缺失项的风险指标为 null；不能因为一个指标缺失把全部卡片清零。

### CALC-049 迟到结果不改写冻结结果

- 优先级：P1
- 前置：查询截止时间后再到达一条旧业务时间的源结果。
- 步骤：先读取并记录截止时间内的当前结果，再注入/等待迟到结果，分别查询未冻结结果、已锁定账单和页面状态。
- 期望：未冻结的结果按真实事件时间修订；已锁定账单不被行情或迟到记录静默改价；页面清楚区分当前结果和冻结结果。

### CALC-050 汇总不按分页计算

- 优先级：P0
- 前置：总览或策略列表超过一页，且第二页包含金额和收益率不同的对象。
- 步骤：分别读取第一页、后续页和不分页的完整筛选集合，独立汇总金额并按最终定义计算比率，再核对总览接口和页面。
- 期望：金额汇总使用完整筛选集合；不能只把当前页相加；比率不能简单平均，需按最终定义重新计算。
