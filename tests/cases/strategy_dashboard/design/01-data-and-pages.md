# 策略看板：数据接入与页面结果级用例

## 使用边界

本文件只验证“策略侧最终结果 → 看板接口 → 页面展示”的数据和页面链路，共 60 个独立场景。测试不写策略库、不重算策略算法、不调用控制或清算写接口；源数据使用测试环境已经存在的最终结果，必要时用固定夹具或只读查询选取样本。

字段校验只按字段说明、单位、正负号、状态语义和页面映射对照。不会把快照血缘、公式版本、审计字段或权限作为本文件的强制前置条件。页面中尚未确认的时间窗口、时区、Sortino 口径等，以“待定”记录，不擅自判定业务结论。

### 通用执行约定

1. 记录测试账号、策略、查询时间、筛选条件、接口响应和页面截图；金额和百分比用接口原值核对，不能用页面截断或格式化后的值反推。
2. 每个场景至少准备一组正向样本和一个对照样本；对照样本可以是同一接口返回中的第二条记录。
3. 步骤中的“调用对应查询接口”指项目现有封装的只读接口，不在用例中拼接 URL、写 SQL 或写入业务数据。
4. “页面一致”表示接口字段、页面字段和页面计算后的显示值在同一查询条件下相互对应；若产品定义明确为不同口径，则按该定义分别核对。
5. 每条用例的“期望”均按三层执行：先核对接口返回字段/集合（接口断言），再核对页面字段/状态/交互（页面断言），最后核对该条写明的临界输入、分页、空值或口径限制（边界断言）。为避免把同一结果重复抄三遍，三层断言合并写在一条期望中。

## 一、策略侧结果接入与字段映射（20 条）

本模块的可控假数据和逐阶段接入边界见 [基础数据接入可控数据场景](../ingestion-boundary-cases.md)。38 个子场景沿用下列主用例编号，已设计但尚未注入真实接入链路，不能按结构检查通过计作业务覆盖。

### SD-101 完整账户资金字段映射

- 优先级：P0
- 来源：PDF S4/D3；原型总览和账号详情；旧用例 SD-01、BV-01
- 前置/数据：选取有净入金、钱包余额、保证金、已实现盈亏、未实现盈亏、手续费、资金费的运行中账号 A。
- 步骤：
  1. 读取策略侧最终账户结果，记录上述字段、币种、时间和状态。
  2. 调用看板账户/总览查询接口。
  3. 打开总览和账号详情，逐字段对照接口与页面。
- 期望：每个字段均有对应值；名称、单位、币种、时间和正负号符合字段说明；页面不把一个字段映射成另一个字段。

### SD-102 费用与资金费正负号

- 优先级：P0
- 来源：PDF S4/M02；原型算法说明；旧用例 SD-04、CM-01
- 前置/数据：准备支出手续费 C>0、收到资金费 F>0、支付资金费 F<0 的三个结果样本。
- 步骤：
  1. 分别记录源结果中的费用和资金费原值。
  2. 查询看板接口并查看总览、策略详情和账号详情。
  3. 对照数值方向和字段标签。
- 期望：手续费支出不显示为收益；资金费收到为正、支付为负；截断后仍非零的负数必须保留负号。非百分比绝对值小于0.0000000001的数截断为数值0时，接口原值和字段的收支含义保持不变，不能将显示零当成没有发生费用或资金费。

### SD-103 金额、百分比和时间显示格式

- 优先级：P1
- 来源：PDF D 契约；原型高保真页面；旧用例 SD-04、BV-08
- 前置/数据：准备带多位小数的正负 USDT 金额、非 USDT 数值、百分比、价格、数量和带秒级时间的样本；价格与数量标明实际单位，复用 page_display_boundaries.json 中 USDT、普通数值、极小数及百分比边界数据。
- 步骤：
  1. 记录接口原值及币种、时间时区，确认百分比源字段是小数比率ratio还是百分数percent。
  2. 查看页面卡片、表格、详情和时间轴。
  3. 先按实际单位确认百分比源值：百分比转换后向零截断2位；USDT与其他普通数值统一向零截断6位，非百分比且0<绝对值<0.000001时10位，极小数先截断再压缩连续前导零为{n}。
  4. 核对USDT和其他非百分比的正负阈值±0.000001及10位后归零，百分比不进入极小数规则；按原值排序并对照同一字段在不同位置的显示。
- 期望：不做四舍五入，也不对负数向负无穷取整。USDT及其他普通数值1.23456789显示1.234567、-1.23456789显示-1.234567；ratio=0.123456789和percent=12.3456789均显示12.34%；非百分比（含USDT）的0.00000089显示0.{6}89，0.00000099999显示0.{6}9999，±0.000001使用普通6位规则。价格、数量需确认实际单位及数值类别，不能将百分比或极小数一概按普通6位处理。截断为数值0时，不改写源值或判为缺失；所有类别末尾补零和千位分隔样式不额外强制。只改变显示精度，不改变排序或计算输入；时间带有约定时区；本轮USDT显示6位不报Bug。

### SD-104 外部运行状态与本地绑定状态分离

- 优先级：P0
- 来源：PDF S1/S2/第 5 节；原型策略管理；旧用例 SD-03
- 前置/数据：同一账号存在本地已绑定但外部 stopped、外部 running 但本地关系已结束两种样本。
- 步骤：
  1. 读取外部运行状态和本地绑定状态。
  2. 查询策略管理、账号管理和详情接口。
  3. 在页面查看绑定、运行、生命周期字段。
- 期望：两个状态分别展示；绑定不被当作正在运行，停止不被当作解绑；页面不因一个状态覆盖另一个状态。

### SD-105 外部运行 ID 与本地策略 ID 映射

- 优先级：P0
- 来源：PDF S1/S2/S3；策略详情原型；旧用例 SD-02、SD-07
- 前置/数据：准备一个本地策略 ID 与外部运行 ID 不同的策略。
- 步骤：
  1. 记录本地策略 ID、外部策略/运行 ID 和账号 ID。
  2. 查询策略列表及策略详情。
  3. 从列表进入详情并核对详情中的身份字段。
- 期望：接口和页面稳定显示各自 ID；跳转、关联和明细不把外部运行 ID 当作本地策略 ID。

### SD-106 同名策略按 ID 区分

- 优先级：P0
- 来源：PDF 关联和去重规则；原型策略列表；旧用例 SD-02
- 前置/数据：准备两个名称相同但策略 ID/运行 ID 不同的策略。
- 步骤：
  1. 查询策略管理和总览策略明细。
  2. 分别点击两个同名策略的详情。
  3. 对照关联账号、金额和运行状态。
- 期望：两条记录独立存在；详情不会串到另一条同名策略；汇总按 ID 计数而非按名称合并。

### SD-107 同名账号按稳定账号身份区分

- 优先级：P0
- 来源：PDF 关联和去重规则；账号管理原型；旧用例 SD-02
- 前置/数据：准备同名但交易所、环境或稳定账号身份不同的两个账号。
- 步骤：
  1. 查询账号列表并记录 ID、交易所和环境。
  2. 分别进入账号详情。
  3. 核对策略集合、资金和持仓。
- 期望：账号不因名称相同而合并；每个详情使用自己的资金和策略；总数按稳定身份去重。

### SD-108 一账号多策略归属

- 优先级：P0
- 来源：PDF S2/S3；原型账号详情；旧用例 SD-02、SD-07
- 前置/数据：准备一个账号同时关联策略 A、B，且两策略有独立归属结果。
- 步骤：
  1. 查询账号详情的策略集合。
  2. 分别打开 A、B 的策略详情。
  3. 对照账号级金额与策略归属明细。
- 期望：账号只计一个账号；策略集合包含 A、B；策略页只显示自身归属绩效，不能把完整账号资金复制给每个策略。

### SD-109 一策略多账号归属

- 优先级：P0
- 来源：PDF S2/S3；原型策略详情；旧用例 SD-02、BV-05
- 前置/数据：准备策略 A 关联账号 1、账号 2，两个账号结果不同。
- 步骤：
  1. 查询策略详情的关联账号列表。
  2. 分别进入两个账号详情。
  3. 核对策略页汇总与账号明细。
- 期望：两个账号均可追溯；策略汇总按合法归属加总一次；同一金额不会因分页或跳转重复累加。

### SD-110 重取和重复事件去重

- 优先级：P0
- 来源：PDF 关联和去重规则；原型执行明细；旧用例 SD-09
- 前置/数据：准备同一订单、成交、资金事件在源结果中存在重复读取或重复事件记录。
- 步骤：
  1. 查询首次结果并记录明细数及汇总。
  2. 刷新或再次查询同一条件。
  3. 对照明细 ID、数量和金额。
- 期望：重取不新增业务事实；订单、成交、资金事件按业务身份去重；汇总前后不变化。

### SD-111 运行状态枚举映射

- 优先级：P0
- 来源：PDF 第 5 节；原型策略/账号管理；旧用例 SD-03
- 前置/数据：准备 running、starting、stopping、stopped、paused、faulted/error、未知枚举样本。
- 步骤：
  1. 查询状态字段和状态更新时间。
  2. 查看策略列表、账号列表和详情。
  3. 对照页面标签和状态筛选结果。
- 期望：已定义枚举按文档语义展示；未知或非法状态显示未知/异常，不静默改成已停止；状态筛选不误归类。

### SD-112 混合策略状态的账号汇总

- 优先级：P0
- 来源：PDF 第 5 节；原型账号管理；旧用例 SD-03
- 前置/数据：账号 A 下有一个 running 策略和一个 stopped 策略，另准备全 stopped 对照账号。
- 步骤：
  1. 查询账号状态及其策略集合。
  2. 查看当前数据账号计数和列表。
  3. 切换历史累计并再次查看。
- 期望：账号只计一个；有 running 时按账号聚合规则展示运行中/混合状态；不能同时把同一账号计入运行中和停止两个账号数量；历史记录仍保留。

### SD-113 历史归属不被当前负责人改写

- 优先级：P1
- 来源：PDF S2；原型策略/账号详情；旧用例 SD-03
- 前置/数据：策略历史上负责人为 X，当前负责人为 Y，且历史绩效可查询。
- 步骤：
  1. 查询历史区间内策略和负责人字段。
  2. 查询当前区间和账号详情。
  3. 对照历史绩效归属与当前配置。
- 期望：历史结果按当时有效关系展示；当前负责人变化不改写历史数据；当前页和历史页字段含义清楚区分。

### SD-114 绑定结束不删除历史结果

- 优先级：P0
- 来源：PDF S2/S5；原型策略详情、账号详情；旧用例 SD-03、SET-16
- 前置/数据：准备已解绑或绑定结束、但有历史运行和收益的账号策略关系。
- 步骤：
  1. 查询当前数据和历史累计。
  2. 打开策略详情的历史数据和账号详情。
  3. 核对历史运行段、收益和账务关联。
- 期望：当前数据按页面定义排除非运行关系；历史数据保留既有结果；解绑不删除旧收益、持仓或账务记录。

### SD-115 stopped 账号的遗留持仓

- 优先级：P0
- 来源：PDF 第 5 节；原型账号详情；旧用例 SD-06
- 前置/数据：准备 stopped 账号仍有未平仓持仓和浮盈。
- 步骤：
  1. 查询账号状态、持仓和权益。
  2. 打开账号详情和持仓区域。
  3. 切换运行时间或历史数据区间。
- 期望：状态显示已停止，遗留持仓和浮盈仍按结果展示；停止不被解释成已平仓；运行时长不因遗留持仓继续增加（若页面展示该字段）。

### SD-116 持仓价格字段语义区分

- 优先级：P0
- 来源：PDF D7/S4；原型策略详情持仓；旧用例 SD-06、BV-09
- 前置/数据：准备含开仓均价、损益两平价、标记价、最新成交价、强平价的持仓。
- 步骤：
  1. 记录源持仓各价格字段。
  2. 查询持仓接口并打开策略详情。
  3. 对照每列标题、值和单位。
- 期望：开仓价不代替损益两平价；标记价不代替最新成交价；强平价“不适用”和“未获取”按原状态区分。

### SD-117 多空持仓与数量单位

- 优先级：P0
- 来源：PDF D7/M20；原型持仓区域；旧用例 SD-06
- 前置/数据：准备多头、空头、币本位/张数单位和合约乘数不同的持仓。
- 步骤：
  1. 记录方向、数量单位、乘数和名义价值。
  2. 查询持仓明细及摘要。
  3. 对照方向、数量、名义价值和持仓数。
- 期望：方向不丢失；币/张单位和乘数正确展示；总名义按说明计算；不同方向的非零持仓不被合并成一个模糊数量。

### SD-118 空仓与零持仓展示

- 优先级：P1
- 来源：PDF D7/M20；原型账号详情；旧用例 SD-06、SD-10
- 前置/数据：准备完整空仓结果、数量为 0 的仓位和持仓集合缺失三类样本。
- 步骤：
  1. 查询三类样本的接口返回。
  2. 打开持仓摘要和明细。
  3. 对照页面空态、0 值和缺失显示。
- 期望：完整无持仓显示空仓/0；真实零值显示 0；集合缺失显示不可用或错误状态，不伪造为空仓。

### SD-119 信号、批次、计划和订单关联

- 优先级：P0
- 来源：PDF D6/D7；原型策略详情执行明细；旧用例 SD-07、BV-10
- 前置/数据：准备一条信号对应批次、计划、意图、订单和成交的执行链，另有取消/替换计划。
- 步骤：
  1. 查询执行明细并记录各层业务 ID、状态和时间。
  2. 在策略详情依次打开信号、批次、计划、订单和成交区域。
  3. 对照父子关系和取消/替换记录。
- 期望：链路按 ID 关联且不串链；取消和替换不重复计数；目标数量为 0 的计划按其原语义展示，不被删除。

### SD-120 部分成交和未平仓成交

- 优先级：P0
- 来源：PDF D7；原型执行明细；旧用例 SD-07
- 前置/数据：准备部分成交订单、有效成交但尚未平仓的开仓成交、已冲销成交。
- 步骤：
  1. 查询订单和成交最终结果。
  2. 查看策略详情的订单/成交表和收益明细。
  3. 对照成交有效性、数量和收益归属。
- 期望：部分成交按实际执行数量计入；未平仓开仓成交不被记为亏损或平手；已冲销事实不重复进入有效成交。

## 二、接口结果与页面展示（24 条）

长文本、大金额、密集图表、不同数据类型和窄容器的可控展示数据见 [页面展示边界子场景](../page-display-boundary-cases.md)。这批 24 个数据变体关联现有主用例；主用例数量不变，页面结果须由真实渲染和交互验证。

### BV-101 总览“运行中数据”口径

- 优先级：P0
- 来源：原型 overview_current；PDF O/P1；旧用例 BV-01
- 前置/数据：准备运行中、已停止、已废止账号各至少一个。
- 步骤：
  1. 调用总览接口选择运行中数据。
  2. 打开总览“当前数据”Tab。
  3. 对照策略数、账号数、资金卡片和明细集合。
- 期望：当前数据只包含页面定义的运行中对象；卡片和明细使用同一筛选集合；停止/废止对象不被混入当前资金汇总。
- 自动化：`test_source_current_overview.py` 的18项覆盖真实当前来源的账户范围、8项明细源值、5项金额独立求和及缺失完整性；`test_source_current_overview_queries.py` 的28项扩展真实分页/筛选、单账户、账户组合、指标单独查询和日期语义，两组合计46个检查实例。见 `docs/strategy-dashboard-current-overview-reconciliation.md`。这是 BV-101 的接口数据部分，不代表 UI 渲染及所有状态转换已验收。

### BV-102 总览“历史累计数据”口径

- 优先级：P0
- 来源：原型 overview_current；PDF O/P1；旧用例 BV-02
- 前置/数据：与 BV-101 相同，保留停止和废止对象的历史结果。
- 步骤：
  1. 切换总览“历史累计”Tab。
  2. 调用对应查询接口。
  3. 对照历史账号/策略集合与累计卡片。
- 期望：历史集合按照页面说明包含可纳入的历史对象；当前运行状态不误删历史结果；当前和历史数字不相互复用。

### BV-103 日期筛选只影响定义为区间的结果

- 优先级：P0

- 期望：页面截断仅影响展示；不把 Top6 误报为全量 100%；若存在“其他”，金额和比例与接口定义一致。

### BV-134 交易明细字段与收益归属

- 优先级：P0
- 来源：PDF D7；原型策略详情；旧用例 BV-10、SD-120
- 前置/数据：准备多订单、多成交、部分成交及开仓未平仓交易。
- 步骤：
  1. 查询订单、成交和归属收益结果。
  2. 查看策略详情执行明细。
  3. 对照订单/成交 ID、方向、数量、均价、费用、时间和收益归属。
- 期望：每列对应正确结果；同订单成交均价按有效成交展示；未平仓开仓交易不在页面显示为亏损或平手。

### BV-135 当前数据与真实历史数据的清算展示

- 优先级：P0
- 来源：原型账号详情/确认分润；PDF S5/P2；旧用例 SET-09、SET-10
- 前置/数据：有清算前毛收益 600、清算后当前周期显示 0、真实净值仍保留历史权益的账号。
- 步骤：
  1. 查询清算数据接口并打开分润清算 Tab。
  2. 查询真实净值接口并打开真实净值 Tab。
  3. 对照清算前历史、清算后周期和真实权益。
- 期望：清算展示按页面规则清零当前展示周期；真实净值与历史收益保留；两种 Tab 不互相覆盖。

### BV-136 页面数据与接口响应一一对应

- 优先级：P0
- 来源：本轮链路一致性推导；旧用例 BV-24
- 前置/数据：选择一个包含卡片、表格、曲线和详情的完整样本。
- 步骤：
  1. 保存同一查询条件下的所有只读接口响应。
  2. 逐页记录页面字段和数值。
  3. 对照字段名、ID、金额、状态和时间。
- 期望：页面不使用另一请求或上一查询的字段；同一范围内相同字段一致；仅在文档明确区分口径时允许不同。

### BV-137 过期或未来状态的页面标识

- 优先级：P1
- 来源：PDF 第 4 节质量规则；原型状态显示；旧用例 SD-11
- 前置/数据：准备带过期观测、未来时间或无法解析时间的运行结果。
- 步骤：
  1. 查询接口状态和观测时间。
  2. 打开总览、策略和账号页面。
  3. 对照页面状态标签和资金/持仓字段。
- 期望：过期、未来或非法时间按页面可用状态显示为陈旧/未知；不把异常结果当作当前正常结果；若该状态仅适用于运行状态，其他字段不套用未经批准的阈值。

### BV-138 缺少历史峰值时的回撤展示

- 优先级：P1
- 来源：PDF M09/M10；原型风险卡；旧用例 CM-07
- 前置/数据：准备只有当前权益、没有足够历史峰值的账号。
- 步骤：
  1. 查询权益曲线和回撤结果。
  2. 打开总览风险卡和账号详情。
  3. 对照历史样本完整性标识。
- 期望：缺少历史峰值时不伪造完整最大回撤；页面显示不可用/样本不足或明确的已知值范围；不能仅凭当前点推导完整回撤。

### BV-139 曲线缺点与未闭合桶

- 优先级：P1
- 来源：PDF 第 4 节曲线质量；原型总览曲线；旧用例 CM-07、CM-09
- 前置/数据：准备中间缺点、单真实点和当前未闭合时间桶。
- 步骤：
  1. 查询曲线点和点状态。
  2. 打开总览/详情曲线。
  3. 对照缺点、单点、未闭桶和统计指标。
- 期望：缺点断开而不是补 0；单点可见；未闭桶只标真实截止时间；补点不进入回撤、波动率等统计。

### BV-140 真实数据和页面缓存更新

- 优先级：P1
- 来源：原型 30s 刷新；PDF 质量规则；旧用例 SD-08、SD-09
- 前置/数据：在两个查询间让源结果发生可识别变化（例如未实现盈亏或持仓数量变化）。
- 步骤：
  1. 查询并记录第一次接口和页面结果。
  2. 等待配置刷新或手动刷新，读取第二次结果。
  3. 对照更新时间、金额、持仓和状态。
- 期望：新结果正确替换旧结果；更新时间跟随源结果；未变化字段不被随机重算；刷新不重复累加。
