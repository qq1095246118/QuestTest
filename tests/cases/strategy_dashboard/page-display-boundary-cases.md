# 分润平台：可控数据的页面展示边界

本文件补充用户要求的“数据是否显示得下、不同类型是否看得清楚”。共 24 个页面数据子场景，沿用已有 SD-103 和 BV 主用例的编号、标题；子场景各自保留固定中文标题。当前状态均为 **DESIGNED_NOT_RENDERED（已设计，尚未在真实页面渲染验证）**。

本批将 [基础数据接入可控场景](ingestion-boundary-cases.md) 延伸到显示结果，并增加长文本、坐标轴、图例、提示框和容器大小相关输入。原始主用例为 175 条，当前注册目录为 226 条；不将新数据文件或文档检查折算为页面通过数。

## 测试数据

[page_display_boundaries.json](../../data/strategy_dashboard/page_display_boundaries.json) 保存逻辑数据集、子场景、操作步骤、预期、关联的接入子场景和待映射的真实契约。

- `datasets` 是未接到真实端点的逻辑展示数据。适配真实只读响应时需保持数值、身份、单位、时间和状态，不可猜测产品响应字段。
- 映射时以字段完整的固定正常响应为基线，仅替换场景指定字段。长文本场景保留相邻非空金额（例如123456.78 USDT）及页面已有操作控件，不能用空白列证明没有遮挡。显式缺字段、null、空集合和失败输入不得由正常基线补回。
- `dataset_refs` 按每条 `actions` 说明选择使用。同屏对照、逐组切换、顺序刷新三种含义已在操作中区分。
- `ingestion_fixture_refs` 是接入场景的覆盖关联，不保证整个输入结构一一等同。端到端执行时应以该次实际注入后返回的同一账户/事件/查询结果为页面基线。
- 默认候选视口为 1440×900；窄容器场景另考察 1366×768、1024×768及侧栏展开。正式必测尺寸必须落在产品支持范围，未承诺移动端适配不自动纳入。
- 长名称和大数值先对照真实字段范围。超出合法业务范围的原始响应只用于前端健壮性观察，不能据此判定平台应允许创建此业务数据。
- 金额以十进制字符串保存；到真实接口的类型转换和页面精度分别按该字段定义执行。
- `display_precision_policy` 保存用户确认的展示规则。数值样本中的 `expected_numeric` 是截断后的十进制值，`expected_display` 不含单位（百分号除外）、去除可选末尾补零，不额外强制补零或千位分隔样式，USDT不再例外。这些预期属于测试侧，映射时不能注入产品响应代替真实组件计算。
- 缺点数据集中，未闭合桶从00:03开始，桶终点为00:04，实际观测截止为00:03:30（均为UTC）；映射时保留三者的不同含义，不能把计划桶终点显示为已观测截止。

## 两条可执行路径及其结果含义

**页面单层验证**：在真实分润平台前端已发出的指定只读查询请求处，用映射后的合成响应替换返回值，保持真实页面及组件代码运行。这样能够独立验证长文本、数值、曲线和状态的展示，无需先具备策略源数据库写权限。结果只记为页面验证，不证明后端接入、计算或接口实现正确。

**完整链路验证**：通过前一批合成源数据驱动真实接入，再查询平台接口并打开真实页面。接入结果、接口原值和页面显示三部分独立核对。不能用本地仿制页面、自己生成的示意图或仅有接口200代替真实页面证据。

当前项目尚未绑定本批所需的真实页面 URL、读取接口的完整响应映射和组件定位，因此本次没有打开真实业务页面、注入响应或声称 UI 自动化通过。上述两条是执行设计，尚未实现本批浏览器执行器。

## 每条场景的操作顺序

1. 确认当前页面、查询条件、对象 ID、组件位置与实际字段格式；记录本次数据子场景编号。
2. 在只读查询响应处加载数据，或使用真实接入后的查询结果，等待该次请求完成且组件实际渲染。
3. 对卡片、表格、图表分别核对文本/数据含义，再按场景执行悬停、查看详情、图例切换、表格滚动、侧栏展开或刷新。
4. 保存原始输入/实际响应、渲染后的截图以及关键交互后的截图或结构化浏览器证据。只看到响应里有该值，不能证明画面里可读。
5. 对照下表和数据文件内的具体预期判定；恢复该场景的响应替换和查询上下文，避免后一场景继承上一场景的图例隐藏或错误状态。

## 展示判定规则

2026-09-22在线稿同步规则见 [UI稿同步基线](../../../docs/strategy-dashboard-ui-baseline-20260922.md)。原型明确要求策略管理和账号管理操作列固定在右侧；这两页的固定列不再只按“如果已支持则检查”处理。精度采用用户最新确认的规则：USDT撤回固定两位例外，与其他普通数值统一6位；百分比2位；非百分比极小数10位，全部向零截断。本轮USDT显示6位不报Bug。以上更新不改变本文件24个子场景的编号、中文标题和未执行状态；旧编号SD-103-ROUNDING及其标题保留便于追溯，其中“舍入”现在仅指向零截断。

### 容器、遮挡与完整信息

- 长文本允许换行、截断、折叠或局部滚动；具体样式以设计为准。固定断言是相邻数值和操作不被覆盖，完整关键信息存在可到达的查看方式。
- 表格本来允许横向滚动时，不因内容宽于视口就直接判为溢出 Bug。检查滚动区域、固定列、分页和操作是否仍可使用。
- 图表提示框可以通过 portal 显示在绘图区外；只要关键内容在实际可视区域可读、定位合理，就不要求它必须被包含在绘图区内。
- 自动化可结合容器边界、元素可见性、点击可达性和截图检查；单看 `scrollWidth > clientWidth` 不能覆盖上述允许行为。

### 数值、状态与数据类型

- 金额、比率、数量、倍数和时长分别核对标签与单位。逻辑样本中 ratio=1.25 对应125%；若真实接口以percent存值，则先按真实契约映射。
- USDT与其他普通数值统一向零截断到小数点后6位；例如 `1.23456789 USDT → 1.234567 USDT`，末尾补零不额外强制。
- 百分比先按源单位转换，再向零截断到2位，不得重复乘100或显示为极小数格式。价格、数量等须核对实际单位及数值类别，不能将百分比或极小数一概按普通6位处理。
- 非百分比且 `0 < abs(x) < 0.000001` 时向零截断到小数点后10位，再将首个非零数前连续小数零的数量写为 `{n}`：USDT或BTC数量 `0.00000089 → 0.{6}89`，`-0.00000089999 → -0.{6}8999`。10位指小数位数，不是有效数字位数；恰好 `±0.000001` 使用普通规则。
- 非百分比极小数如 `±0.00000000009 USDT/BTC` 截断后为数值0。原始非零值仍用于计算和排序，不把截断后的0改写成缺失或底层真实0。不额外要求所有tooltip提供超出展示精度的原值。
- 使用十进制原值核对，不能先转成二进制浮点再制造边界进位/丢位。正负数均向零截断，如 `-1.23456789 USDT → -1.234567 USDT`、`-1.23456789 BTC → -1.234567 BTC`；所有类别末尾补零样式不另设强制规则。
- 正支出手续费和正收益不是同一含义，不以正负号或颜色独自决定业务类型；字段名称、单位与说明必须能让用户辨认。
- 真零、不可用、请求失败和完整空集合应可区分。错误恢复后同步更新金额及状态；旧值保留须按既有页面规则明确标旧。

### 曲线、坐标和系列

- 在默认完整视域下，正负极值应被正确表达；用户主动缩放或按设计筛选后的截取不算数据丢失。不强制所有折线轴都从0开始。
- 共用纵轴导致小数量级系列近似平坦，可能是正确比例关系；检查小值在提示或明细中可查询、不被改成真实0，不自行要求改用双轴或对数轴。
- 密集时点允许减少刻度文字，TopN图表按正式规则选择系列；检查名称、单位、身份与数据点对应，不要求所有标签同时展示。
- BV-139 已规定缺点断开、不补0，本批复用该规则。单点、双点、全零和常量非零分别检查，不将缺失和真实平线混用。
- SVG与Canvas图表均需检查真实渲染和悬停结果；Canvas中不能仅因DOM没有文字节点就判缺值，也不能因配置中有值就判渲染通过。

## 重点示例：长图例和边缘提示框

- 载入 BV-136-TOOLTIP-EDGE，系列名称使用长中文，点同时包含正值和负值。
- 在真实曲线最左、最右和上下极值点依次悬停。
- 核对每次提示的系列名称、该点时间、数值和单位；移动后不能残留上一个点的值。
- 检查提示框没有被图表父容器或浏览器边缘裁掉。允许换边显示、调整位置或约定的内部滚动。
- 展开已有侧栏后重复检查；若产品支持该桌面宽度，提示和曲线仍须可用。
- 保存交互后的页面证据。只检查接口或图表配置对象不能完成此场景。
